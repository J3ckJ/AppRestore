# AppRestore GUI

PySide6 desktop UI matching the v5 mockup.

```bash
pip install '.[gui]'
apprestore-gui --demo
python -m apprestore_gui --demo --screenshot-dir /tmp/gui-shots
```

Fonts: Onest (OFL) in `resources/fonts/`.
Artwork: public iTunes Lookup API, cached under the AppRestore cache directory.
