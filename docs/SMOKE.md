# Чек-лист проверки на живом устройстве (smoke)

**Правило:** нет заполненного чек-листа — нет релиза. См. [`RELEASING.md`](RELEASING.md) §2.1.

**Кто прогоняет:** Евгений (вход в Apple ID — только он). Лена готовит форму и сверяет, что в логах/скринах нет секретов.  
**Версия под проверку:** ________ (например 0.3.2)  
**Дата / МСК:** ________  
**Кто прогонял:** ________

В колонке **Факт** — что увидели. **Статус:** `ok` / `fail` / `skip` / `blocked`.  
В логах, скринах и этой таблице **нет** Apple ID (email), пароля, кода 2FA, пароля связки ключей, UDID, токенов, полных путей с именем пользователя. Пишите «сессия открыта», «код принят», «устройство A», без идентификаторов.

| A4 | Экран приветствия / дисклеймер | Есть «не связан с Apple», «свой Apple ID», без запроса пароля до действия пользователя | | |

## E. Бесплатное получение (только с согласием)

| # | Шаг | Ожидаемый результат | Факт | Статус |
|---|---|---|---|---|
| E1 | Выбрать бесплатное, которого **не было** на аккаунте | Без согласия / без галочки — скачивание не берёт лицензию; понятная подсказка | | |
| E2 | Явное согласие на **это** приложение (галочка или диалог) | Текст: добавится в покупки, отменить нельзя; `price==0` | | |
| E3 | Успех | Приложение ставится; факт получения можно найти в журнале лицензий (без Apple ID) | | |
| E4 | Платное без оплаты | Отказ с понятным текстом; лицензия не создаётся | | |

**Важно:** каждый E2/E3 — только после отдельного «да» Евгения на конкретное приложение. Не гонять пачкой.

### Блокеры релиза (автоматически «нельзя»)

- Падение при входе (0xc0000142 и аналоги) на поддерживаемой ОС.  
- Цикл 2FA.  
- Лицензия взята без явного согласия.  
- Секреты в журнале/логах/скринах.  
- Выход не удаляет сессию.  
- Не прогнан минимум окружений из §H.
