# Смоук 4b на живом iPhone (короткий)

Сборка: `--ui quick` (4b). Аккаунт и iPhone Евгения. Сеть на компьютере есть, если не сказано иначе.
Отметка: ✅ / ❌ + одна строка, что видно. Скриншоты без почты, UDID и путей с именем пользователя.
Любой ❌ в пунктах со знаком ⛔ — стоп, сборку дальше не тестируем, пишем в чат.

## 0. Перед стартом
1. Записать `read_counts` (сегодня / всего) — сверим в конце.
2. Свободное место на iPhone (Настройки → Основные → Хранилище).

## 1. Запуск и вход
3. Приложение запускается (Windows: без `0xc0000142`), онбординг проходит до конца, ссылки шага 3 видны.
4. Вход с 2FA: код вводится в 6 ячеек; неверный код — понятный текст и возврат к форме; «Отмена» прерывает вход.
5. ⛔ Ни в окне, ни в логах (`~/.apprestore/`, вывод терминала) нет пароля, кода 2FA, пароля связки ключей, cookie, токена. Почта — только в замаскированном виде.
6. Сетевая ошибка входа (выключить сеть): текст «Проверьте подключение…», слова VPN нет.

## 2. Главный экран и «Что вернуть»
7. Телефон определяется, список приложений с телефона совпадает с реальностью, иконки настоящие или серая заглушка.
8. Группа «Нет в регионе» не показана, пока нет данных (пустой не бывает).

## 3. Установка
9. Сгруженное приложение (уже на аккаунте): ставится, этапы «Скачивание N %» → «Установка» → «Готово». ⛔ Счётчик лицензий не изменился.
10. Не хватает места на iPhone: установка не начинается, нехватка округлена вверх.
11. Без сети на компьютере: сгруженное возвращается, всё, что идёт через шлюз, неактивно с подписью.

## 4. Лицензии (самое важное)
12. ⛔ Бесплатное приложение, которого нет на аккаунте, через «Поставить»: перед покупкой есть уведомление, после — +1 в `read_counts`, запись в журнале со статусом `acquired`.
13. ⛔ «Вернуть все N» с K > 0: экран согласия сам не закрывается; «Отмена» — ничего не ставится, счётчик не изменился; «Только уже купленные» — новых лицензий 0.
14. ⛔ Платное приложение в «Вернуть все» и в K не попадает; покупки платного нет нигде.
15. Лимит (если упёрлись): список «не хватило лимита», «место освободится в HH:MM» в местном времени, в очередь на завтра само не встало.
16. Отказ Apple (удалённое приложение, 2040 или `-128`): понятный экран, в журнал не записано, повтора нет. На `-128` основная кнопка «На главный»; после «Войти заново» установка сама не продолжается.

## 5. В конце
17. ⛔ `read_counts` = значение из п. 1 + число лицензий из п. 12–13, лишних записей нет; журнал только дописывался.
18. ⛔ «Выйти» (лист «Apple ID», с подтверждением): сессия и `purchases-cache.json` стёрты, повторный запуск просит вход; журнал лицензий и `read_counts` не изменились.

19. ⛔ Удалённое приложение с неизвестной ценой (флаг `region_probe`): попытка проходит через экран согласия; после — проверить историю покупок Apple ID (reportaproblem.apple.com или Настройки → Apple ID → Покупки): списаний нет. Явный отказ Apple — без записи в журнал.
