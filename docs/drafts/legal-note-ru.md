# Записка Евгению: что решить по праву и безопасности (L-1)

10.10.2026, МСК · Лена · полный разбор: [`docs/LEGAL.md`](../LEGAL.md)

Это не юридическое заключение и не гарантия. Коротко: что опасно, что поправить в коде, что решить тебе.

## Три главных «нет» в текущем коде

1. **Проба полки через `--purchase` (`shelf_probe.py`).**  
   Если Apple отвечает «нужна лицензия», программа сама вызывает `download --purchase`. Успех = лицензия уже на Apple ID, даже если скачивание оборвали на 1%. Фоновый режим гоняет это по всем ~33 приложениям полки.  
   **Нужно:** проба только без purchase (`download` / `list-versions` / `list-purchases`). Никакого «granted».

2. **Кнопка «Поставить» в новом GUI всегда берёт лицензию.**  
   `installStore` и `acquireStore` оба зовут `acquire_license=True`. Галочки/диалога нет. Сохранение копий с телефона тоже всегда с `acquire_license=True`.  
   **Нужно:** «Поставить» = только уже имеющаяся лицензия; «Получить бесплатно» = отдельная кнопка + диалог на каждое приложение + проверка `price == 0` + журнал и лимит (как ты подтвердил для bench: 5/сутки, 15 всего).

3. **Выход в старом окне не чистит vault.**  
   В Quick UI `signOut` удаляет копию сессии; в Widgets `_revoke` — только `ipatool auth revoke`, файлы в `~/.apprestore/keychains/` остаются. Плюс нет жёстких прав на файлы vault.

## Что можно оставлять (с условиями)

| Тема | Решение |
|---|---|
| Redownload уже купленного / сгруженного | Можно — смысл продукта, п. H условий Apple |
| Старые версии (`list-versions` + externalVersionId) | Можно, только при своей лицензии |
| «Мои покупки» (`list-purchases`) | Можно и нужно — честная основа полки |
| MDM-lookup, Range-докачка, JSON-ошибки, swdist | Можно |
| Несколько Apple ID (vault) | Можно после chmod + forget при выходе |
| Полка банков / VK / MAX | **Тебе решить** (см. ниже) |

## Что нельзя никогда

- Подмена storefront / «сменить регион», чтобы открыть чужой каталог (условия Apple: Home Country).
- Обход DRM, чужие аккаунты, платные без оплаты, VPP/machine auth без отдельного решения.
- Фоновые пачки `--purchase`.

## Полка убранных приложений — твоё решение

Файл `popular_apps.py` сам по себе ничего у Apple не запрашивает. Риск в **позиционировании**: «вернём банки, которые Apple убрала», плюс санкционный контекст (часть банков / OFAC). Программа не раздаёт IPA — их отдаёт Apple на аккаунт с лицензией. Но жалобу на репозиторий или внимание к аккаунту это не отменяет.

Варианты:
- **A.** Оставить полку + жёсткий текст «только если уже было на вашем Apple ID» + никогда не звать purchase с полки.  
- **B.** Сузить (убрать банки, оставить VK/MAX/Mail).  
- **C.** Убрать до консультации юриста.

Макс уже проверил: публичный каталог по этим id пуст во всех странах — без лицензии Apple не отдаст. Обещать «вернём любой из списка» нельзя.

## Неофициальный клиент

В условиях Apple есть фраза «only using Apple’s software». ipatool этому не соответствует — это серая зона всего класса инструментов, не только нас. Практический риск: Apple ограничивает Apple ID. В README уже есть «не связан с Apple»; нужно то же на экране входа и фраза, что Apple может ограничить аккаунт.
