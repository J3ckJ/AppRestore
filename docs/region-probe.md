# region_probe — «Нет в регионе» / «Удалено из App Store»

Модуль: `region_probe.py` (stdlib, без ipatool). Тесты: `test_region_probe.py` (51, без сети).
Правовая рамка: `LEGAL.md` §1.10 (Лена, 10.10.2026).

## Как работает
Для каждого track_id из списка пользователя — публичный `GET https://itunes.apple.com/lookup?id=<ids>&country=<cc>`
(до 50 id в одном запросе). Совпадение `trackId` в `results` = приложение есть в витрине.

1. Витрина аккаунта: есть → `AVAILABLE`; ошибка → `UNKNOWN`.
2. Нет в витрине аккаунта → эталонные витрины `REFERENCE_STOREFRONTS = ("US", "RU")` по очереди
   (вторая спрашивается только для тех, кого не нашла первая; совпадающая со страной аккаунта пропускается).
   - есть хотя бы в одной → `NOT_IN_REGION`
   - нет ни в одной, и подтверждено отсутствие во ВСЕХ эталонных, которых минимум две → `DELISTED`
     (витрина аккаунта засчитывается как эталонная, только если она сама из списка: US-аккаунт = US + RU)
   - эталонная одна (настроено `("US",)`) или хоть одна упала → `UNKNOWN` (косвенных данных мало, не блокируем)

## Известная цена (LEGAL.md §1.14 п.2)
`classify_detailed()` / `classify_region_detailed()` → `dict[int, RegionResult]`:
`RegionResult(status, known_price: float | None, known_prices: Mapping[str, float])`.
Цена берётся из поля `price` тех же ответов lookup (новых запросов, витрин и заголовков нет),
только там, где приложение нашлось, и только конечное число ≥ 0 (иначе — неизвестна).
`known_price = max(known_prices)` или `None`. Для `DELISTED`/`UNKNOWN` — всегда `None`.
Вторая эталонная не опрашивается, если приложение нашлось в первой, поэтому цен обычно одна.

Контракт для вызывающего: в `license_guard` передаётся `price` = МАКСИМУМ всех известных цен
(витрина аккаунта + `known_price`). Любая > 0 → отказ «платное». Только если цена неизвестна везде,
`price=None` + `region_unavailable=True` открывают путь §1.14. `classify()` не изменился.

Кэш: по (track_id, страна), цена хранится вместе с «есть», «есть» — 24 ч, «нет» — 6 ч, ошибки не кэшируются. Rate-limit: ≤1 запрос/с,
общий на процесс (`classify_region` использует один `RegionProbe`). Дедуп и отброс невалидных id на входе.
Максимум запросов на вызов: 3 × ⌈N/50⌉.

## Соответствие §1.10
| Условие | Как соблюдено |
|---|---|
| 1. Анонимно | Свой urllib-opener без cookie/auth-хендлеров; заголовки только `User-Agent: AppRestore-region-probe/1` и `Accept`; в URL только `id` и `country`. Модуль не импортирует `ipatool_api`/`license_guard`, сессию/токен/DSID/`X-Apple-Store-Front` не видит. Страна — ISO2 (storefront-id вида `143441-1,34` отвергается). Тесты проверяют заголовки, URL, отсутствие cookie-хендлера. |
| 2. Только список пользователя | Вход — track_id снаружи; внутри нет поиска/генерации id. Лимит 2000 id на вызов как защита от обхода каталога. |
| 3. 1–2 фиксированные витрины, кэш, частота | Константа `("US","RU")`, >2 → `ValueError`; кэш с TTL; ≤1 запрос/с; батчи по 50. |
| 4. Только подпись | Возвращает `RegionStatus`; тексты в `LABELS_RU` без действий (тест на «VPN/купить/смен/регион/войти»). Ничего не покупает. |

Логи: только счётчики (число id/запросов/ошибок), без track_id, страны и тел ответов.

## Подписи (RU)
| Статус | Подпись | Группа |
|---|---|---|
| AVAILABLE | — | не попадает |
| NOT_IN_REGION | «Нет в App Store вашей страны» | «Нет в App Store вашей страны» |
| DELISTED | «Удалено из App Store» | «Удалённые из App Store» |
| UNKNOWN | «Не проверено» | остаётся, где было |

Подписи осторожные: классификация косвенная (1–2 витрины). Тексты вынесены в `DEFAULT_LABELS_RU` /
`DEFAULT_GROUP_TITLES_RU`; правка без изменения кода — `make_labels({"delisted": "…"})`,
`make_group_titles({...})`, `label_ru(status, labels)`.

## Оговорки
- Отсутствие в US и RU ≠ гарантированно удалено везде (могло остаться в третьей стране) — это сознательная цена запрета перебора стран.
- iTunes lookup иногда отдаёт пустой ответ для живого приложения (кэш CDN); поэтому «нет» кэшируется короче.
