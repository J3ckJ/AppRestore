# Поставка патченого ipatool

GUI-релиз AppRestore собирает ipatool автоматически в CI. В ZIP/.app уже входит
готовый бинарник: пользователю не нужно устанавливать Go, выполнять команды
или собирать дополнительный компонент. Упаковщик принимает только архив,
собранный текущим workflow; self-test проверяет обязательные расширения.

## Закреплённые входные данные

- Исходники: `majd/ipatool`, коммит `cde7d00355e152714377b953ec57438626d3cb5a`.
- Go: `go1.25.0`.
- Патчи: `packaging/patches/0001–0005`, каждый проверяется по SHA-256 в
  `packaging/build-ipatool.sh`, порядок применения фиксирован.
- Архив: воспроизводимый tar.gz, фиксированные mtime/uid/gid/gzip headers.

0001 добавляет страну аккаунта в `auth info`; 0002 — всю историю покупок одним
вызовом; 0003 — пароль связки через stdin; 0004 — повторную iOS-загрузку без
публичной карточки с проверкой идентичности ответа; 0005 — безопасную команду
`probe-download`, сравнивающую каналы без покупки и скачивания IPA. Исходный закреплённый
коммит уже содержит исправление редиректов и несколько каналов загрузки.

Подробный аудит возможностей и ограничения: [IPATOOL-AUDIT.md](../docs/IPATOOL-AUDIT.md).

## Сборка для разработчика

На macOS: `bash packaging/bootstrap-ipatool.sh` (потребуются Command Line Tools
для Git и C-компилятора). Скрипт скачивает закреплённый Go при необходимости,
проверяет хэш, собирает архив и устанавливает `bin/ipatool`.

На Windows с Git Bash и Go 1.25.0:

```bash
bash packaging/build-ipatool.sh windows-amd64
```

Результат: `dist/ipatool/ipatool-2.6.0-windows-amd64.tar.gz`. Этот архив передаётся
`packaging/package_gui.py --ipatool-archive <путь>` после PyInstaller.
Прежний `bootstrap-ipatool.ps1` удалён в текущем рабочем дереве и здесь не используется.

Программа из исходников сначала ищет `bin/ipatool(.exe)` в корне репозитория,
затем рядом с Python и в PATH. Локальный `bin/` и кэши `build/` игнорируются Git.

## Проверки до упаковки

1. Проверяются закреплённый коммит, SHA-256 каждого патча и точная версия Go.
2. Генерируются моки и выполняются Go-тесты `pkg/appstore` и `cmd` без Apple ID.
3. Проверяются бинарные маркеры редиректов и 0001–0005, версия 2.6.0.
4. Упаковщик запускает self-test готового GUI и health-check распакованного архива.

Локальная Windows-сборка и тесты проверены 12.10.2026. macOS на этой машине
не проверялся. Эти проверки не подтверждают выдачу конкретного приложения Apple:
для этого нужна отдельная попытка на Apple ID владельца.

## Совместимость старых установщиков

Опубликованный архив `ipatool-2.6.0-redirect` содержит только закреплённый
исходный коммит, но не патчи AppRestore. Он оставлен для старых CLI-установщиков.
GUI workflow его больше не использует. Нельзя незаметно подставлять другой
архив под его прежний SHA-256: новые CLI-архивы нужно отдельно опубликовать
и обновить закреплённые хэши всех платформ.

Сборка не читает пароль Apple ID, пароль связки или аккаунт; сетевые обращения
нужны только для исходников, Go и зависимостей. Секреты не попадают в бинарник.
