# AppRestore 4b · Спецификация, часть 3: онбординг

База — `variant-4b-onboarding.html` (`src/onboard.py`), рендеры `variant-4b-onboarding-1…4.png`, `-onboarding-all.png`. Модель — `ui4b/onboarding.py` (`Onboarding.step()`, `stepper()`), свойства `Restore4b.onboardingStep`, `stepper`, `scanCaption`, `scanEta`, `scanFraction`, `scanFound`; слоты `onboardingStart()`, `onboardingLater()`. Сетка, шрифты, кнопки, телефон — как на главном (часть 1). Типографика macOS/Windows — часть 2, §7.

## 1. Шаги и переходы (уже в коде)

| # | Название в степпере | Когда | Уходим дальше |
|---|---|---|---|
| 1 | Привет | `!started` | «Начать» → `onboardingStart()` |
| 2 | Подключение | `!connected` | **сами**, когда телефон подключён и доверяет |
| 3 | Apple ID | `!signedIn && !appleIdSkipped` | **сами** после входа; «Позже» → `onboardingLater()` |
| 4 | Проверка | `!scanDone` | сами → главный экран (`finished = true`) |

Если телефон отключили на шаге 3–4 — обратно на 2 (это даёт `step()` сам). Онбординг показывается один раз; флаг «пройден» хранится в настройках **[проверить: сейчас `Onboarding.finished` только в памяти]**.

## 4. Таблица «Зачем Apple ID» (шаг 3)
Ширина 520, верх 1px `ink`, строки padding 12/0, низ 1px `line`, `tableRow` 18/400 + значение `tableValue` 18/650:
- Сгруженные — **не нужен**; Свой файл IPA — **не нужен**; Удалённые из App Store — **нужен**.
- Цвета значений: в концепте `ok` #2F9E55 (2.84:1 на фоне) и `accent` (#B35128 — 4.23:1 на фоне) — для 18 px мало. В QML: «не нужен» — `okText` #217A40 (4.45), «нужен» — `errorText` #A04824 (5.06) **[предл.]**.

## 5. Скан (шаг 4)
- Полоса 520×10, радиус 5, дорожка `stepOkBg`, заливка `ink` по `scanFraction`; анимация ширины `durBase`.
- Подпись `scanCaption` 15/600 tnum («Проверено 218 из 640») + справа `scanEta` `ink2` 450 («ещё около минуты» / «почти готово» / «ещё около N минут» — `scan.eta_text`). Без total — «Проверено 218», без ETA.
- Счётчики (`scanFound`): число `foundNum` 22/700 tnum над подписью 16 `ink2`, gap 28: «сгруженных», «удалённых из App Store». Растут по ходу скана. **У Димы сейчас 0 сгруженных во время скана** — `scanFound` считает из `selection.items`, которые приходят после скана; нужен счётчик из прогресса (`ScanCounter.found`) **[нет в коде: заполнять found по ходу]**.
- Склонение подписей по числу (`formatting.plural`).

## 7. Доступность и клавиатура
- Шаг 1: фокус на «Начать». Шаг 2: фокус на ссылке «Не получается подключить»; смена шага объявляется (`Accessible.announce` / live region) «iPhone подключён, шаг 3 из 4». Шаг 3: фокус на «Войти в Apple ID». Шаг 4: прогресс как `ProgressBar` с `Accessible.name` = подпись + ETA.
- Таблицу шага 3 читаем строками: «Сгруженные: Apple ID не нужен».

## 8. Расхождения с текущей вёрсткой Димы (по `dima-4b/screenshots/onboarding-*`)
1. Шаг 1: у Димы экран телефона выключен (тёмный) — в концепте иллюстрация с пустыми местами.
