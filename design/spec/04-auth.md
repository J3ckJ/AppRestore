## 3. Код 2FA
- 6 ячеек 62×70 (Win 52×60), радиус 12 (Win 6), фон `surfaceSoft`, цифра `codeDigit` 32/650 tnum; между 3-й и 4-й — доп. зазор 14; текущая — #FFF + кольцо 2 `ink`.
- Реализация: **одно** скрытое `TextInput` (`inputMask`/валидатор `\d{0,6}`, `inputMethodHints: Qt.ImhDigitsOnly`), ячейки — отрисовка. Так работают вставка, Backspace, автозаполнение кода macOS.
- **Вставка**: ⌘V / Ctrl+V целиком; из буфера берём только цифры («482 913», «482-913» → 482913); больше 6 — первые 6.
- На 6-й цифре — сразу `submitCode()` **[предл.]** (кнопку оставить для клавиатуры).
- **«Отправить снова» нет**: в коде (`AppleLogin`, ipatool) повторной отправки нет. Вместо кнопки — подсказка: «Код не пришёл — нажмите «Отмена» и войдите ещё раз, Apple пришлёт новый.»
- Неверный код: ipatool не даёт повторить, процесс входа завершается → состояние `auth-code-wrong`. Сейчас `_explain_login_failure` для этого случая отдаёт общий «Вход не удался (код N). Текст ipatool показан выше.» — в 4b никакого «текста выше» нет. Нужна ветка распознавания неверного кода **[нет в коде]** (по транскрипту ipatool; образец строки проверить у Макса).

## 4. Прочие ошибки (тексты из `_explain_login_failure`)
| Случай | Текст в листе |

Текущая строка в `auth_pty._explain_login_failure` (сетевая ветка) должна быть заменена на эту **[нет в коде]**. Рендер `variant-4b-auth-signin-network.png`: поле без кольца ошибки (пароль верный), текст ошибки под паролем, пароль не стираем. |
| HTTP 204 / 301 | короткий вариант **[предл.]**: «Apple не приняла вход. Попробуйте ещё раз позже.» (технические детали — в журнал, не в лист) |
| Почта без «@» / пустой пароль | тексты `login()`: «Укажите почту Apple ID.», «Введите пароль. Программа его не сохраняет.» |

## 5. «Отмена» во время входа
В `running`/`need_code` «Отмена» должна останавливать процесс: `AppleLogin.cancel()` есть, слота в `QuickSession` нет — `cancelLogin()` **[нет в коде]**. До этого «Отмена» в `running` неактивна.

## 6. Клавиатура и доступность
- Esc = «Отмена»; Enter — «Войти» / «Подтвердить» / «Открыть». Tab: почта → пароль → кнопка → «Отмена».
- Поле пароля: `echoMode: TextInput.Password`, без «показать пароль» в v1 **[предл.]**.
- Ошибка объявляется (`Accessible.description` поля + announce); фокус возвращается в поле с ошибкой.
- Ячейки кода — одно поле с `Accessible.name` «Код подтверждения, 6 цифр, введено 3».
