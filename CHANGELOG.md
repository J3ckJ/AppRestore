# История изменений

Все заметные изменения проекта документируются в этом файле.

## 0.1.4 — 2026-07-29

### Добавлено

- macOS bootstrap `install.sh`: одна проверяемая команда загружает закреплённый
  source ZIP, сверяет SHA-256 и запускает user-space установку без `sudo`;
- команда `apprestore` устанавливается в `~/.local/bin`, а PATH настраивается
  для текущего терминала явным `export` и сохраняется для новых shell;
- macOS release/bootstrap contract и CI-проверки безопасной упаковки;
- Windows-обновление теперь полностью готовится и проверяется в staging,
  а неудачная подмена автоматически возвращает предыдущую рабочую версию;
- install/uninstall принимают только каталог с AppRestore marker либо строгим
  SHA-256 fingerprint опубликованной v0.1.3 и не удаляют произвольный объект.

### Безопасность

- Windows-пути установки вычисляются через Known Folder API, а launcher
  использует переносимый `python.exe -m apprestore_core.cli`;
- macOS venv получает exact managed marker; чужой venv/launcher не заменяется,
  а ошибка удаления старого backup не отменяет уже проверенную установку;
- release builder отвергает symlink/reparse/non-regular inputs, проверяет
  согласованность версий и записывает корректный regular-file mode в ZIP.

## 0.1.3 — 2026-07-28

### Добавлено

- GitHub-native release contract для `J3ckJ/AppRestore`: versioned archive URL,
  bootstrap `install.ps1` и `SHA256SUMS.txt`;
- минимальный Windows CI с проверкой Python 3.10 и 3.12, PowerShell 5.1/7,
  полного набора тестов и воспроизводимой release-сборки;
- `SECURITY.md`, руководство для участников и безопасная GitHub issue form.

### Изменено

- основной one-line installer переведён на
  `github.com/J3ckJ/AppRestore/releases/latest/download/install.ps1`;
- endpoint сайта E.L System Tools сохранён как совместимое зеркало;
- краткое уведомление `LICENSE` заменено полным текстом GNU GPLv3 и явным
  уведомлением `GPL-3.0-or-later`;
- release timestamp обновлён для воспроизводимых архивов версии 0.1.3.

### Исправлено

- test import layout теперь одинаково работает с `unittest` и полным `pytest`.

### Безопасность

- документация для issue и security reports запрещает публиковать IPA,
  Apple ID, 2FA-коды, passphrase, токены и необработанные логи с UDID.

## 0.1.2 — 2026-07-27

### Добавлено

- в интерактивное меню Windows возвращён оригинальный ASCII-логотип AppRestore из macOS-версии;
- цветной баннер автоматически включается только в совместимом живом терминале, а перенаправленный вывод остаётся без ANSI-кодов;
- текущий macOS-лаунчер снова показывает тот же фирменный баннер.

## 0.1.1 — 2026-07-27

### Исправлено

- добавлен проверяемый online-bootstrap: одна PowerShell-команда скачивает и устанавливает versioned release;
- команда `apprestore` становится доступна сразу в том же PowerShell без перезапуска;
- source-лаунчер всегда обновляет старую установленную копию и больше не принимает устаревший `$LASTEXITCODE` за ошибку установки;
- при отсутствии Python установщик ставит пользовательский Python 3.12 через `winget`, а без него — через закреплённый по SHA-256 официальный installer;
- для распаковки ipatool больше не требуется системный `tar.exe`;
- обычный запуск сразу открывает меню и больше не инициирует установку Apple-драйвера или UAC;
- код возврата повышенного процесса `winget` передаётся без потери;
- пути iMazing на Windows учитывают перенаправленные `%APPDATA%` и `%LOCALAPPDATA%`;
- устранены повторный запрос redownload на iPhone и повторный online-поиск App Store ID при retry;
- JSON-ответ `download --json` больше не смешивается с диагностическим выводом.

### Безопасность

- passphrase хранилища ipatool удалён из аргументов процесса и переменных окружения; секреты вводятся непосредственно в интерактивный ipatool.

## 0.1.0 — 2026-07-27

### Добавлено

- единое Python-ядро для macOS и Windows;
- Windows launcher и пользовательский PowerShell-установщик;
- закреплённые версии `pymobiledevice3==10.1.0` и `ipatool v2.3.1`;
- проверка SHA-256 Windows-архива ipatool до распаковки;
- интерактивное меню без аргументов (`apprestore`), как `./apprestore.sh` на macOS;
- `apprestore setup` и автоустановка Apple Mobile Device Support через winget на Windows;
- команды диагностики, поиска устройств, сканирования, загрузки, установки и восстановления;
- безопасный деинсталлятор с отдельной явной очисткой пользовательских данных.

### Безопасность

- точная проверка bundle ID по внутреннему `Info.plist`;
- запрет неявного выбора последнего скачанного IPA;
- интерактивная передача пароля, 2FA и пароля хранилища напрямую в ipatool;
- исключение IPA, окружений и локальных секретов из Git.
- проверка версии bundled ipatool на Windows (хеш архива сверяется только установщиком);
